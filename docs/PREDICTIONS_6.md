# PREDICTIONS 6: hysteresis 통계량 D와 광도의 관계 (독립 표본)

- 작성일: 2026-11-17. 이 문서의 1–7절은 독립 표본(sample_v2)을 만들기 전에, 그 자료를 받기 전에 커밋한다.
- 8절(합성 자료로 구한 문턱값과 검정력)은 두 번에 걸쳐 채운다. 먼저 목록 수준의 정보(적색편이, 광도)만으로 어림한 값을 자료를 받기 전에 적고, 자료를 받아 동결한 뒤 실제 cadence와 오차로 다시 계산해 확정한다. 확정도 D를 계산하기 전에 커밋한다.
- 커밋 뒤에 규칙과 다르게 한 것은 보고서의 "사전 등록과 다르게 된 점"에 적는다.

## 1. 배경과 이미 본 것

- 5b단계(sample_v1, 주 표본 225개)에서 hysteresis 통계량 D의 중앙값이 +0.23이었다(측정 가능 71개, 95% 구간 0.20–0.25). 같은 W2 초과 flux에서 변한 성분이 밝아질 때 더 푸르다는 뜻이다.
- 이 값은 "W2가 W1보다 늦게 반응한다"(밴드 간 지연)와 "먼지 재형성이 늦다" 둘 다로 나올 수 있어 가르지 못했다.
- **이미 본 결과**: 5b의 사후 확인에서 D와 log L_bol의 순위 상관은 −0.05(p = 0.68, 63개)였다. 이것은 sample_v1에서 본 것이므로 같은 표본으로 시험할 수 없다. 그래서 겹치지 않는 표본을 새로 만든다.
- 이 문서를 쓰는 시점에 sample_v2의 광도곡선은 받지 않았고, 어떤 천체가 들어갈지도 계산하지 않았다.

## 2. 두 모형과 사용자 예측

> - 모형 1 (밴드 간 지연): 지연이 먼지 반지름에 비례하고 R ∝ L^(1/2)이므로, 관측자 기준 지연 ∝ (1+z) L^(1/2). D는 광도와 양의 상관.
> - 모형 2 (재형성 지연): D는 광도와 뚜렷한 양의 상관이 없다.
> - 사용자 예측: 새 표본에서도 D는 광도와 양의 상관을 보이지 않는다(모형 2 쪽).

**이 시험이 가를 수 있는 것과 없는 것.** 시험하는 것은 "D가 (1+z) L^(1/2)를 따라 커지는가"다. 양의 상관이 없다고 나와도 재형성 지연이 확인되는 것은 아니다. 광도와 무관한 밴드 간 반응 차이(예: 모든 천체에서 비슷한 크기의 뭉개짐 차이)도 상관을 만들지 않는다. 따라서 가능한 결론은 "밴드 간 지연이 반지름–광도 관계대로 커진다는 모형 1과 맞는다 / 맞지 않는다"까지다.

## 3. 지연–광도 관계의 기준값 (문헌)

Lyu, Rieke & Smith (2019, ApJ 886, 33; arXiv:1909.11101)의 식 15와 16(PG quasar 87개. 3단계에서 본문을 읽고 THEORY.md 식 8–9로 옮긴 것):

```
Δt_W1 / day = 10^(2.10±0.06) (L_AGN / 10^11 L_⊙)^(0.47±0.06)
Δt_W2 / day = 10^(2.20±0.06) (L_AGN / 10^11 L_⊙)^(0.45±0.05)
```

같은 논문의 초록은 크기 비를 R_K : R_W1 : R_W2 = 0.6 : 1 : 1.2로 적었다.

**모형 1의 기준 정의** (중심값만 쓴다): 관측자 기준 밴드 간 지연

```
δ(L, z) = (1 + z) [Δt_W2(L) − Δt_W1(L)].
```

L = 10^10, 10^11, 10^12 L_⊙에서 정지계 값은 13.6, 32.6, 75.2일이다. 먼지의 반응 자체의 지연(장난감 모형의 `lag_days`)은 (1+z) Δt_W1(L)로 둔다.

- L_AGN에는 BASS DR2의 `logLbol`을 넣는다. Lyu et al.의 L_AGN과 BASS의 L_bol은 구하는 방법이 다르다(확인하지 않았다). 그래서 지연의 크기를 0.5배, 2배로 바꾼 경우를 민감도 확인으로 함께 계산한다.
- 이 관계는 PG quasar(대체로 L > 10^11 L_⊙)에서 나온 것이다. 더 어두운 Seyfert로의 외삽이다.

sample_v1과 같은 목록, 같은 기준에서 **적색편이 범위만** 바꾼다. 광도 범위를 넓혀 모형 1의 지연 차이가 커지게 하려는 것이다.

| E0 | | sample_v1의 231개 제외 (적색편이 범위로 이미 겹치지 않지만 명시) |

- 5a단계에서 z 규칙 때문에 빠졌던 0.040 < z ≤ 0.050의 천체(39개)는 광도곡선을 받은 적이 없으므로 sample_v2에 들어간다.
- 표본 크기의 목표는 두지 않는다. 기준을 통과한 것을 모두 쓴다. 측정 가능한 천체가 7절의 최소 수에 못 미치면 다른 목록으로 보충하지 않고 "표본 부족"으로 보고한다(보충하면 선택 기준이 달라져 해석이 흐려진다. 요청의 "부족하면 보충"은 하지 않기로 하고 그 이유를 여기 적는다).
- 비교 별 선택에는 5a단계에서 찾은 RA 0°/360° 경계 문제가 있는 함수를 그대로 쓴다(같은 절차를 유지하기 위해서다. 영향은 RA 0° 근처 시야에서 별이 한쪽에 몰리는 것이다).
- funnel은 `targets/sample_v2_funnel.json`에 남긴다.

## 5. 절차 (B2)

1. sample_v2의 표적과 비교 별 목록을 만들어 커밋한다(자료를 받기 전).
2. 5a단계와 같은 방식으로 NEOWISE-R, AllWISE MEP, unTimely를 받는다(manifest에 조회 조건과 해시).
3. blind 품질 확인: 표적에 대해서는 개수, 오차 크기, 두 측광 차이의 흩어짐만 계산한다. 광도곡선을 그리거나 D, 증가폭, 색을 계산하지 않는다.
4. 오차 바닥을 5a와 같은 규칙으로 정하고 광도곡선을 동결한다(`data/frozen/sample_v2/`, 해시는 `data/freeze_v2.json`).
5. 실제 cadence와 오차로 8절의 문턱값을 확정해 커밋한다.
6. 그 뒤에 처음으로 D를 계산한다.

## 6. 통계량

- **D**: 5b단계와 같은 코드(`breath.measure`), 같은 설정(`breath.SETTINGS`), 같은 '측정 가능' 기준(구간마다 쓰는 방문 4개 이상, σ_D ≤ 0.10). 오차는 바닥을 넣은 값.
- **대상**: sample_v2에서 D가 '측정 가능'하고 BASS DR2의 `logLbol`이 있는 천체.
- **설명 변수**: x = log10(1 + z) + 0.5 log10 L_bol. 모형 1이 지연이 비례한다고 한 양의 로그다.
- **주 통계량**: D와 x의 Spearman 순위 상관 ρ.
- 함께 적는 것: D와 log L_bol의 ρ, 광도 상위 절반과 하위 절반의 D 중앙값 차이, D의 중앙값과 95% bootstrap 구간.

## 7. 판정 규칙

두 문턱값을 쓴다.

- **q2**: "D와 x가 무관하다"일 때 ρ의 95번째 백분위. 실제 표본의 D를 천체 사이에서 무작위로 섞어(10,000번) 구한다.
- **q1**: 모형 1일 때 ρ의 5번째 백분위. 장난감 모형에 3절의 지연을 넣고, sample_v2의 실제 방문 시각·오차·적색편이·광도로 합성 표본을 만들어(표본 크기는 실제 '측정 가능' 수에 맞춤) ρ의 분포를 구한다. 8절에서 확정한다.

| 판정 | 조건 |
|---|---|
| **사용자 예측 지지** (양의 상관을 보이지 않음. 모형 1과 맞지 않음) | ρ ≤ q2 이고 ρ < q1 |
| **사용자 예측 기각** (모형 1 쪽) | ρ > q2 이고 ρ ≥ q1 |
| 판정불가 | 그 밖. q1 ≤ ρ ≤ q2(검정력이 부족해 두 모형의 범위가 겹치는 곳), 또는 q2 < ρ < q1(양의 상관은 있으나 모형 1보다 약함) |
| 판정불가 (표본 부족) | 대상이 20개 미만 |

- 최소 표본 수 20은 순위 상관이 안정되는 최소한으로 잡은 값이다. 검정력(모형 1이 참일 때 ρ > q2가 될 확률)은 8절에서 계산해 적고, 80%에 못 미치면 그 사실을 실제 자료 전에 적는다.
- 모형 1의 지연 크기를 0.5배, 2배로 바꾼 q1도 함께 계산해, 판정이 그 선택에 따라 달라지는지 적는다. 판정 자체는 기준 정의(1배)로 한다.
- **D의 재현** (B3의 첫 항목): sample_v2에서 단측 Wilcoxon 부호 순위 검정(D > 0)이 p < 0.05이면(8개 이상) "부호가 재현됨"으로 적는다. 크기는 중앙값과 95% 구간을 5b의 값(+0.23, 0.20–0.25)과 나란히 적는다. sample_v2는 더 멀고 밝아서, 모형 1이면 D가 더 커야 한다.
- 두 표본을 합친 결과는 참고로만 적는다. sample_v1의 D–광도 관계는 이미 본 것이기 때문이다.

확정하는 것:

- **q1은 이 표의 "모형 1" 열의 첫 값이다.** 실제 '측정 가능' 수 n이 격자 사이면 선형 보간하고, n이 100을 넘으면 N = 100의 값(+0.45)을 쓴다. 지연 0.5배, 2배의 q1도 같은 방식으로 읽어 민감도로 적는다.
- **검정력**: 모형 1이 참일 때 N = 20에서 82%, 30에서 95%, 40 이상에서 99% 이상이다. 최소 표본 수 20에서 80%를 넘는다. 지연이 절반이면 N = 20에서 73%로 80%에 못 미치고 N = 25부터 넘는다.
- **필요한 천체 수**: 80%에는 20개(지연이 절반이면 25개), 95%에는 30개(지연이 절반이면 40개)다.
- q1이 q2(참고값)보다 커지는 것은 N ≥ 35부터다(8.1절의 어림에서는 40). N이 20–30이면 q1 ≤ ρ ≤ q2인 "판정불가" 구간이 남는다.
- 실제 오차가 어림에 빌려 쓴 sample_v1의 오차보다 작아(오차 바닥의 중앙값 W1 8.0 mmag, sample_v1은 17.3 mmag), 장난감 모형에서 '측정 가능'한 천체가 163개 중 약 84개로 어림(약 50개)보다 많다. 실제 수는 실제 AGN의 변광 크기에 달려 있다.

실제 자료를 보기 전에 적어 두는 한계:

- **모형 2에서 ρ > q2가 되는 비율이 5%가 아니라 6–9%다.** 모형 2의 ρ 중앙값이 0이 아니라 +0.02–0.03이기 때문이다. 재형성 시간은 광도와 무관하게 넣었지만 먼지 반응의 지연 (1+z) Δt_W1(L)은 광도에 따라 달라지고, 그것이 D에 약하게 남는다. 따라서 "사용자 예측 기각" 쪽의 위양성률은 이 장난감 모형 기준으로 5%보다 조금 높다.
- q1은 driver의 크기, host 비율, 재형성 없음 같은 가정에 달려 있다. 모형 1에 재형성 지연이 함께 있는 경우는 계산하지 않았다. 그 경우 D의 흩어짐이 커져 ρ가 낮아질 수 있으므로, "ρ < q1"은 "이 장난감 모형의 모형 1(밴드 간 지연만 있음)과 맞지 않음"을 뜻하고 밴드 간 지연이 아예 없다는 뜻이 아니다.
- 장난감 모형은 L_bol을 오차 없이 안다고 둔다. BASS DR2의 `logLbol`에는 천체별 불확실성이 있을 것이고(크기는 이 문서에서 확인하지 않았다), 그만큼 실제 ρ는 모형 1이 참이어도 이 표보다 낮아진다. 그 크기는 계산하지 않았다.
- 대상은 L_bol이 있는 천체뿐이다(210개 중 163개).

## 9. 보조: 밴드 간 평균 지연의 직접 추정 (B4)

- 방법: 천체마다 W2 flux를 W1 flux와 그 시간 미분으로 회귀한다. F2(t) = a + b F1(t) + c dF1/dt이면 W2의 지연은 δ = −c/b다(F1(t − δ) ≈ F1(t) − δ dF1/dt). 미분은 이웃 방문의 중심 차분으로 구한다. 표본 전체의 δ를 가중평균한다.
- **먼저 합성 자료로 검증하고, 통과할 때만 실제 자료에 적용한다.** 통과 조건(모두):
  1. 지연 0, 20, 40, 80일을 넣은 합성 표본(실제 cadence·오차, 표본 크기는 실제와 같게)에서 가중평균 δ의 편향이 넣은 값의 30% 이하이거나 10일 이하.
  2. 같은 조건에서 표본 평균의 1σ 정밀도가 15일 이하.
  3. 밴드 간 지연이 없고 재형성 지연만 있는 합성 표본(τ_re = 1, 2, 5년)에서 가중평균 δ가 ±10일 안.
- 3번이 실패하면 이 방법은 지연과 재형성을 가르지 못하는 것이므로 적용하지 않는다. 방문 간격이 6개월이므로 실패할 가능성이 있다. 그 경우 "6개월 간격에서 가능한 정밀도"만 보고한다.
