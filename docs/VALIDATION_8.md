## 1. 이미 본 것 (기준을 쓰기 전에)

기준이 결과를 알고 만들어졌다는 점을 숨기지 않으려고 적는다.

- **D의 분포를 봤다.** sample_v1: '측정 가능' 71개, 중앙값 +0.228 (95% 구간 0.200–0.248). sample_v2: 94개, 중앙값 +0.268 (0.241–0.295), **94개 모두 D > 0**. 단측 Wilcoxon p는 2 × 10⁻¹³, 1.9 × 10⁻¹⁷.
- **D와 광도의 관계를 봤다.** sample_v2에서 ρ(D, x) = +0.129 (n = 70), 등록 규칙으로는 "모형 1의 세기의 상관 없음".
- **장난감 모형의 결과를 봤다.** 5b의 검증(`results/s5b_validation.json`)에서 재형성 지연도 밴드 간 지연도 없는 경계 이동 모형(τ_re = 0)은 D의 중앙값이 0.00(16–84% −0.05 ~ +0.05)이었다. 즉 **장난감 조건(독립인 오차, DRW·ramp driver, 장난감의 방문 시각)에서는 추정량이 치우치지 않았다.** 밴드 간 지연 10, 30, 90일은 D = +0.07, +0.13, +0.53을, 재형성 지연은 +0.03 ~ +0.10을 냈다. 6B의 장난감 표본(실제 방문 시각과 오차)에서는 모형 1의 D 중앙값 +0.36, 모형 2 +0.12였다.
- **아직 하지 않은 것**: 실제 표본의 방문 시각·오차·오차 공분산을 쓴, 색 루프가 전혀 없는 null 자료에서의 D. 공유 peak와 blackbody 변환을 쓰지 않는 직접 비교. unTimely 측광으로 잰 비대칭. scan 방향에 따른 차이. driver의 변광이 질량·광도에 따라 달라질 때의 모형 1의 ρ.
- 표본의 모든 천체가 D > 0라는 것은 추정량이나 자료 처리에서 온 치우침일 가능성을 시사한다. 이 단계는 그 가능성을 먼저 본다.

## 2. 해석 규칙 (미리 고정)

1. **직접 비교(B2)까지 비대칭을 지지하면**: null test(B1)에서 추정량의 치우침이 관측값보다 충분히 작고, 직접 비교의 부호와 크기가 3.2절의 "지지" 조건을 만족하면, 색 비대칭이 자료에 있다고 보고 transfer-function 모형 비교(B5의 설계)로 갈 근거가 된다. 이 경우에도 원인(밴드 간 지연, 재형성, kernel의 폭)은 정해지지 않은 채다.
2. **약해지거나 사라지면**: 기존의 D > 0가 어느 분석 단계에서 생겼는지(기준 방문의 선택, 공유 peak, 구간 정의, 오차 구조, 측정 가능 기준, 온도 변환)를 밝히는 것을 이 단계의 결과로 한다. 이때 5b·6B의 판정 문구는 그대로 두고 "그 통계량이 무엇을 재고 있었는지"를 추가 분석으로 적는다.
3. B1이 "치우침 있음"이면 B2의 직접 비교도 같은 null 자료로 먼저 시험하고, 직접 비교가 null에서 치우치지 않을 때만 그 결과를 쓴다.
4. B3은 B1·B2의 결과와 무관하게 수행하고, 6B의 판정이 가정에 얼마나 기대는지를 적는 데만 쓴다.

## 3. 시험과 통과/실패 기준

### 3.1 B1. D 추정량의 null test

**null 자료.** 천체마다 동결 광도곡선의 방문 시각과 오차(바닥 포함)를 그대로 쓴다. W2의 참값은 관측된 방문 flux로 둔다(실제 변광의 폭과 모양을 보존). W1의 참값은 두 가지다.

- **(a) 선형**: F1 = c + a·F2. (c, a)는 그 천체의 관측된 (F2, F1)에 직선을 맞춘 값. 초과 flux로 쓰면 ΔF_W1 = a·ΔF_W2가 정확히 성립한다.
- **(b) 하나의 T(t)**: 변한 성분이 넓이가 고정된 blackbody이고 온도만 변한다(제자리 가열, `breath.heating_in_place_excess`). 기준 상태(가장 어두운 세 방문)의 W2 flux 가운데 먼지의 몫은 0.5로 두고, 기준 온도는 합성 W1 초과의 합이 관측값과 같아지게 정한다(해가 없으면 700 K). 두 밴드가 같은 T(t)를 지연 없이 따르므로 색은 flux의 한 값 함수다.

두 경우 모두 (F2, F1) 평면에서 곡선이 하나이고 루프가 없다. 참인 D는 (a)에서 0이다. (b)에서는 두 구간이 같은 곡선 위에 있으므로 구간에 따른 차이는 없어야 한다.

- **잡음**: 방문마다 (W1, W2)에 2변량 정규 잡음. 분산은 동결 파일의 오차², 상관계수 r은 천체마다 추정한다: 같은 방문의 (pipeline − unTimely) 차이를 W1과 W2에서 구해 방문들에 걸친 Pearson 상관(쌍 6개 이상). 추정할 수 없는 천체는 표본의 중앙값. 민감도로 r = 0과 r = 0.8.
- **절차**: 합성 방문 자료를 실제와 같은 코드(`breath.measure`, 가장 어두운 세 방문의 기준, 최대 초과에서 온도를 공유하는 두 구간 맞춤, 구간 정의, '측정 가능' 기준 4 + 4개와 σ_D ≤ 0.10)에 넣는다. 방문 수준부터의 전체 절차다. single-exposure 단계와 오차 바닥의 추정 자체는 다시 흉내 내지 않고 바닥 값은 실제 값을 쓴다.
- 표본마다(sample_v1 주 표본, sample_v2) null마다 200번. 참값에 든 잡음의 영향을 보는 민감도로, 참값을 3방문 이동 평균으로 매끈하게 한 경우를 더한다.

**보고**: 회차별 '측정 가능' 수, D의 중앙값, D > 0의 비율, 단측 Wilcoxon p. 이들의 분포를 실제 값과 나란히.

**기준** (표본·null마다):

| 표시 | 조건 |
|---|---|
| 치우침 없음 | 회차별 중앙값 D의 중앙값이 절댓값 0.03 이하이고, D > 0의 비율(평균)이 0.45–0.55이고, 단측 Wilcoxon p < 0.05인 회차가 10% 이하 |
| 치우침 큼 | 회차별 중앙값 D의 중앙값이 0.10 이상이거나, p < 0.05인 회차가 50% 이상 |
| 부분적 | 그 사이 |

**관측값과의 비교**: 실제 중앙값 D가 null의 회차별 중앙값 분포의 99번째 백분위보다 크면 "null로 설명되지 않음", 2.5–97.5번째 백분위 안이면 "null로 설명됨", 그 사이는 "일부 설명됨". 보정한 크기(실제 중앙값 − null 중앙값)도 적는다.

**치우침이 있으면 원인을 가른다.** 한 번에 하나씩 바꾼 변형으로 D의 중앙값이 얼마나 변하는지 본다: (가) 온도를 공유하는 점을 최대 초과가 아니라 평균 log 초과로, (나) 기준 상태를 가장 어두운 세 방문이 아니라 참값으로, (다) 구간 표시를 잡음 없는 참값으로, (라) W1에만 또는 W2에만 잡음(W2는 가로축과 색에 함께 들어간다), (마) 오차 상관 r = 0, (바) 두 구간의 방문 수와 flux 범위가 같은 천체만. 치우침이 없어도 (가)–(마)는 한 번씩 돌려 기록한다.

### 3.2 B2. 공유 peak와 온도 변환 없는 직접 비교

**추정량.** 초과 flux, 기준 방문, 공유 peak, blackbody를 쓰지 않는다.

- 구간 표시는 5b와 같다(정규화한 두 밴드 합의 중심 차분의 부호). 모든 방문에 대해.
- **공통 구간**: 두 구간의 W2 flux 범위가 겹치는 구간 [lo, hi] = [max(두 최솟값), min(두 최댓값)]. 이 안의 방문만 쓴다(외삽 금지).
- 모형: F1 = c + m·F2 + δ·[밝아지는 구간]. 두 변수의 오차를 모두 넣는다(잔차의 분산 s1² + m²s2² − 2·r·m·s1·s2). δ는 **같은 W2 flux에서의 F_W1,rise − F_W1,fade**다. D > 0는 δ > 0(밝아질 때 더 푸름)에 대응한다.
- 효과 크기: 공통 구간의 중심에서 Δ(W1 − W2) = (W1 − W2)_rise − (W1 − W2)_fade (mag). δ > 0이면 음수.
- '직접 비교 가능': 공통 구간 안에 구간마다 방문 3개 이상, 공통 구간의 폭이 W2 오차 중앙값의 3배 이상, Δ(W1 − W2)의 오차 0.03 mag 이하.
- 보조: 구간마다 직선을 따로 맞춰 공통 구간 중심에서 비교한 값(기울기를 같게 두지 않음).

**먼저 null로 시험한다.** B1의 null 자료에 같은 추정량을 적용한다. δ > 0의 비율이 0.45–0.55이고 단측 Wilcoxon p < 0.05인 회차가 10% 이하일 때만 실제 자료의 결과를 쓴다. 아니면 "직접 비교도 null에서 치우침"으로 적고 치우침의 크기를 뺀 값을 참고로만 낸다.

**기준** (실제 자료, 표본마다):

| 표시 | 조건 |
|---|---|
| 비대칭 지지 | δ > 0인 천체의 비율이 0.65 이상이고 단측 이항 검정 p < 0.01, 그리고 Δ(W1 − W2) 중앙값의 bootstrap 95% 구간이 0을 포함하지 않고 음수, 그리고 δ > 0의 비율이 null 회차 분포의 99번째 백분위보다 큼 |
| 사라짐 | Δ(W1 − W2) 중앙값의 95% 구간이 0을 포함하고 δ > 0의 비율이 null 분포의 2.5–97.5번째 백분위 안 |
| 약해짐 | 그 사이 |

종합: 두 표본 모두 "지지"면 **지지**, 두 표본 모두 "사라짐"이면 **사라짐**, 그 밖은 **약해짐**.

- 천체별 표(공통 flux 구간, 구간별 방문 수, δ, Δ색과 오차)와 표본의 부호 비율, 중앙값을 낸다. D를 잴 수 있었던 천체에서 D와 δ의 부호가 같은 비율도.
- **unTimely로 반복**: unTimely 측광(2010–2020)이 두 밴드 모두 10 epoch 이상인 천체에 같은 추정량. 오차는 unTimely의 값(바닥 없음). "같은 방향"의 기준: δ > 0의 비율이 0.5보다 크고 단측 이항 p < 0.05.
- **scan 방향**: WISE는 6개월마다 scan 방향이 반대다. 방문의 홀짝(가능하면 unTimely의 forward 표시로 확인)을 넣은 모형 F1 = c + m·F2 + δ·[rise] + γ·[홀짝]을 맞춘다. 보고: γ의 분포, δ 중앙값의 변화. 변화가 30% 이하면 "scan 방향과 무관", 넘으면 "scan 방향에 기댐".

### 3.3 B3. lag 모형(모형 1)의 재시험

6B의 장난감 표본(`scripts/run_d_lum_power.py`)을 다음과 같이 바꿔 모형 1의 ρ 분포를 다시 계산한다.

- **driver**: DRW의 시간척도와 진폭을 천체마다 다르게. MacLeod et al. (2010, ApJ 721, 1014)의 식 (7)과 표 1: log f = A + B log(λ_RF/4000 Å) + C(M_i + 23) + D log(M_BH/10⁹ M☉). SF∞(mag): A = −0.51, B = −0.479, C = 0.131, D = 0.18. τ(일, 정지계): A = 2.4, B = 0.17, C = 0.03, D = 0.21. DRW의 σ = SF∞/√2. λ_RF = 4000 Å로 둔다. M_i = 90.596 − 2.5 log(L_bol/erg s⁻¹) (Shankar, Weinberg & Shen 2010이 인용한 Shen et al. 2009의 환산 M_i(z=2) = 90 − 2.5 log L_bol과 M_i(z=0) = M_i(z=2) + 0.596). M_BH는 BASS DR2, 없으면 표본 중앙값. 관측계 시간척도는 (1+z)배.
- 대안: 시간척도만 Burke et al. (2021, Science 373, 789)의 τ = 107일 × (M_BH/10⁸ M☉)^0.38로 바꾼 경우.
- **지연–광도 관계의 산포**: Lyu, Rieke & Smith (2019)의 식 15–16(W1: 10^2.10 (L/10¹¹ L☉)^0.47일, W2: 10^2.20 (L/10¹¹ L☉)^0.45일)에 천체마다 공통인 log-normal 산포 0, 0.15, 0.30 dex. 산포의 크기는 가정이다(원문에서 값을 찾지 못했다).
- **선택**: mock 표본에 실제와 같은 '측정 가능' 기준을 적용하고, 통과한 것만으로 ρ를 계산한다(mock의 통과 수도 보고). 보조로 실제로 '측정 가능'했던 70개 가운데 mock에서도 통과한 것만 쓴 ρ.
- 구성: {driver 2가지} × {산포 3가지} = 6가지, 구성마다 200번.

**기준**: 관측값 ρ = +0.129가 mock ρ 분포의 5번째 백분위보다 작으면 그 구성에서 "바깥". 6가지 모두 바깥이면 **"여전히 바깥"**, 일부만이면 **"가정에 달림"**, 모두 안이면 **"바깥이 아님"**. 6B의 판정은 바꾸지 않는다.

### 3.4 B4. 선택 효과와 보고 보완 (기준 없음. 기술)

- sample_v1의 type 분류: type 1 88 + type 2 135 = 223 밖의 2개가 무엇인지. Q1(16개)과 Q2·Q3(20개)의 정의 차이.

- 대표 그림: 효과가 큰 천체와 중앙값 근처 천체 각각의 W1/W2 광도곡선과 색–W2 flux 평면(시간 방향, 두 구간의 공통 flux 구간 표시). 고르는 규칙: sample_v2의 '측정 가능' 94개 가운데 D가 가장 큰 것과 D가 중앙값에 가장 가까운 것(각각 '직접 비교 가능'한 것 중에서).
