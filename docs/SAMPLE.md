# SAMPLE: 근처 hard X-ray 선택 AGN 표본 (sample_v1)

작성: 2026-11-14. 1–3절은 선택 기준을 목록에 적용하기 **전에** 커밋했다. 4절부터는 실행한 뒤에 덧붙였다(각 절 머리에 적은 커밋 참고).

이 표본은 5단계에서 쓴다. 5a단계는 표본을 정하고 자료를 받아 품질만 확인한 뒤 동결하는 단계다. 표적 은하의 광도곡선은 이 단계에서 보지 않는다(6절).

## 1. 기준을 쓰기 전에 본 것

기준이 결과에 맞춰졌을 가능성을 독자가 판단할 수 있도록, 기준을 쓸 때 이미 본 것을 적는다.

- **Swift-BAT 105-month 목록**: 파일의 머리 3줄, 첫 3행, 마지막 3행, 분류 문자열의 종류, NGC 3786과 NGC 2273의 행. 목록 웹 페이지의 분류별 개수 표(Seyfert I 379, Seyfert II 448, LINER 6, Unknown AGN 114, Beamed AGN 158 등).
- **BASS DR2 표**: 열 이름, 첫 3행, `Type`·`Method`·`ztype` 열에 나오는 값의 종류.
- **보지 않은 것**: 적색편이, 은하 위도, WISE 등급에 따른 개수. 어떤 기준에서 몇 개가 남는지는 계산하지 않았다. WISE 시계열 자료는 표본의 어느 천체에 대해서도 받지 않았다(NGC 3786과 NGC 2273은 1–4단계에서 이미 분석했다. 3절).
- **쿼리 시간 시험**: IRSA 쿼리 방식을 비교하려고 NGC 3786의 기준 별(2단계에서 이미 받은 것) 10개를 다시 조회했다. 표본과 무관하다.

## 2. 선택 기준 (S1–S11)

코드: `src/irecho/sample.py`의 `SampleCriteria`, 실행: `scripts/build_sample.py`.

**모집단**: Swift-BAT 105-month hard X-ray 목록(Oh et al. 2018, ApJS 235, 4)의 1,632개 천체. hard X-ray(14–195 keV) 선택은 가림과 host 은하 빛의 영향을 가장 덜 받는 AGN 선택 방법이라 Seyfert 1과 2가 함께 들어온다.

| 기준 | 내용 | 값 | 이유 |
|---|---|---|---|
| S1 | BAT 분류 코드 | 40 (Seyfert I), 50 (Seyfert II), 60 (LINER) | 제트의 synchrotron이 중적외선을 지배하는 beamed AGN(80)을 뺀다. 분류가 없는 Unknown AGN(70)과 여러 천체가 섞인 Multiple(15)도 뺀다 |
| S2 | 적색편이 | 0 < z ≤ z_max. z_max는 아래 규칙으로 정한다 | 가까운 천체만 쓴다 |
| S3 | 은하 위도 | \|b\| > 20° | 별이 빽빽한 시야를 피한다(대조군 기준 C4와 같음) |
| S4 | 황도 위도 | \|β\| < 80° | 황도 극 근처는 WISE가 거의 연속으로 관측해서 "방문 = 하루 이틀 동안의 노출 묶음"이라는 파이프라인의 가정이 깨진다 |
| S5 | BASS DR2 분류 | DR2에 있고 Type이 BZQ, BZB, BZG, BZQ/Lense, Sy1/Lense이면 제외 | BAT 목록이 Seyfert로 적었어도 DR2 분광이 beamed 또는 중력렌즈로 분류한 천체를 뺀다. DR2에 없는 천체는 남긴다 |
| S6 | AllWISE 대응 천체 | BAT counterpart 위치에서 3″ 안. 여럿이면 W1이 가장 밝은 것 | 대조군과 같은 방식 |
| S7 | 포화 여유 | W1 > 8.5, W2 > 8.0 (AllWISE profile-fit 등급) | 단일 노출의 포화가 W1 ≈ 8.0, W2 ≈ 7.5에서 시작한다(`config.SATURATION_WARN_MAG`, 대조군 기준 C3와 같음) |
| S8 | 어두운 쪽 한계 | W1 ≤ 12.5 | 방문 오차 모형을 확인한 별의 범위가 W1 9.5–12.5다(2단계) |
| S9 | AllWISE 품질 | `cc_flags`의 W1, W2 자리가 `00`, `ph_qual`의 W1, W2 자리가 `AA` | 회절 무늬, halo, 잔상, 광학 유령상으로 표시된 천체를 뺀다 |
| S10a | 주변의 밝은 별 | 5′ 안에 W1 < 5.0인 AllWISE 천체가 없을 것 | 심하게 포화된 별의 산란광과 회절 무늬. S9의 플래그가 놓친 경우에 대비한 것 |
| S10b | 섞임 | 12″ 안에 W1 < W1(표적) + 2.5인 다른 AllWISE 천체가 없을 것 | 2 × FWHM 안에 표적 flux의 10% 이상인 이웃이 있으면, 단일 노출마다 둘로 나뉘거나 하나로 합쳐져 측광이 튈 수 있다 |
| S11 | 비교 별 | 아래 조건의 비교 별이 6개 이상 | 방문별 영점 오프셋을 재려면 방문마다 별이 3개 이상 필요하다(`differential.MIN_STARS`). 품질 컷으로 빠지는 별을 감안해 두 배로 잡았다 |

**S2의 z_max 규칙.** 목표 크기는 150–250개다. z_max는 다음과 같이 기계적으로 정한다.

1. S1과 S3–S10을 z ≤ 0.050인 모든 천체에 적용한다.
2. 격자 {0.010, 0.015, …, 0.050} 가운데, 통과한 천체 수가 250개 이하인 가장 큰 값을 z_max로 한다.
3. z_max = 0.050에서도 150개에 못 미치면 그대로 두고 보고한다. 기준을 풀지 않는다.

- 이 규칙이 쓰는 것은 목록의 적색편이와 AllWISE 목록(2010년 관측의 평균 등급)뿐이다. 시계열 자료는 쓰지 않는다.
- 적색편이는 BAT 105-month 목록의 값을 쓴다(모든 천체에 같은 출처). BASS DR2의 적색편이는 함께 적어 두기만 한다.
- S11은 z_max를 정한 뒤에 적용하고, 탈락한 자리를 다른 천체로 채우지 않는다.

**비교 별의 기준 (S11).** 대조군 시야의 비교 별과 같다(`scripts/select_field_stars.py`, PIPELINE.md 6절의 R1–R13).

- 표적에서 1.5° 안, 표적에서 3′ 밖
- W1 9.5–11.5, W1−W2가 −0.15 ~ +0.15
- `cc_flags` `00`, `ext_flg` 0, `nb` 1, `na` 0, 포화 화소 없음, `var_flg` 5 이하, `ph_qual` `AA`
- profile-fit χ² < 3, 2MASS 대응 천체 하나이고 J−Ks ≤ 1.0, 고유운동 < 150 mas/yr
- 15″ 안에 W1(별) + 4 mag보다 밝은 이웃이 없을 것
- 통과한 별 가운데 W1 9.5–10.5에서 5개, 10.5–11.5에서 5개를 무작위로 뽑는다. 난수 seed는 `[20261112, 5, BAT 목록 번호]`다. 표본의 순서나 크기가 바뀌어도 한 시야의 별은 바뀌지 않는다.

**기준에 넣지 않은 것.**

- AllWISE의 변광 플래그(`var_flg`)는 표적에 대해 읽지 않고 표본 파일에도 적지 않는다. 표적의 변광 정보이기 때문이다.
- X-ray 광도, black hole 질량, Seyfert 세부 분류로는 자르지 않는다. 표본 파일에 적어 두기만 한다.
- 문헌에 알려진 changing-look 사건이나 중적외선 섬광의 유무로 자르지 않는다. 그런 천체를 빼면 다음 단계에서 재려는 빈도가 낮아진다.

## 3. calibration 천체

NGC 3786과 NGC 2273은 1–4단계에서 광도곡선을 이미 봤고, 느린 상승 판정식 (b)는 NGC 2273을 본 뒤에 만들었다. 이 둘은 기준을 통과하든 못 하든 표본 파일에 넣고 `role = calibration`으로 표시한다.

- 통과하지 못한 기준이 있으면 `failed_cut` 열에 적는다.
- 다음 단계에서 빈도를 셀 때 분모와 분자 모두에서 뺀다.
- 그 밖의 천체는 `role = science`다.
- 2단계의 대조군 8개 가운데 BAT 목록에 있고 기준을 통과하는 것은 `science`로 들어올 수 있다. 그 천체들의 광도곡선도 이미 봤다. 어느 것이 해당하는지는 4절에 적는다.

## 6. 비교 별

`scripts/build_sample.py stars`를 19:58–20:32에 실행했다. 결과 커밋은 `9fbe19d`다. 이때까지 표본의 시계열 자료는 받지 않았다.

1. **포화 개수가 변광 정보를 조금 담는다.** 표본은 AllWISE 등급으로 포화 여유(W1 > 8.5, W2 > 8.0)를 두고 골랐다. `n_visits_brighter_than_saturation_margin`은 NEOWISE 방문 중 이 한계보다 밝은 방문의 수이므로, 0이 아니면 그 은하가 AllWISE 때보다 밝았던 방문이 있다는 뜻이다. 0이 아닌 표적은 W1 1개, W2 7개다(`results/qa_summary.json`). 개수만 집계했고 어느 은하인지, 언제인지는 찾아보지 않았다. 다만 `qa_targets.json`에는 은하별 값이 들어 있다.

실수로 표적의 광도곡선이나 변광량을 본 일은 없다.
