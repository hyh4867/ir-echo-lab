Equations, units and assumptions

Gray equilibrium: Rsub = [L / (16πσTsub⁴)]½; T = [L / (16πσr²)]¼. Graphite: 1800 K; silicate: 1500 K. Radii are in light-days; luminosities are in erg s⁻¹. [S1, S2]

Shell response Ψ = c/(2R) over 0–2R/c; Lecho = ∫Ψ(τ)L(t−τ)dτ. This toy model heats dust using the smoothed driver. [S3; approximation]

Lν = Σ AπBν(T); Ldust = Σ AσT⁴. Host W1/W2 = 309.540/171.787 gives Vega W1−W2 = 0. [S1, S4]

Fixed area: dlogT/dlogLdust = ¼. An ideal moving sublimation boundary has constant temperature and slope 0; a finite evaporating shell need not follow either limit. [Derived from S1]

Driver: x′=qx+s√(1−q²)Z, q=exp(−dt/τ), L=L₀exp(x) [S5]. TDE-like input: L=L₀[1+a(1+Δt/τ)⁻⁵ᐟ³] after onset [S6]. Step and linear inputs are chosen teaching functions.
