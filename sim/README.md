# Echo Sim

A static, English, mobile-first **toy model** for learning AGN dust echoes, intended as a theoretical companion to `ir-echo-lab` (the pipeline in the parent directory). It does not modify or import that code. No build tools, npm install, external assets or runtime packages are needed.

From this directory: `python3 -m http.server 8769`, then visit `http://localhost:8769`. ES modules require HTTP. Test: `node --test model.test.mjs`. No hosting deployment is included.

## Equations and sources

Every numerical model below is either a cited physical relation or an explicitly chosen educational prescription. Time is in days (86400 s), radii in light-days (c × 86400 cm); internal luminosity, radiance, area and flux use cgs. Temperature is in kelvin.

- **S1:** [OpenStax, Blackbody Radiation](https://openstax.org/books/university-physics-volume-3/pages/6-1-blackbody-radiation). Bν = 2hν³/c² / [exp(hν/kT)−1], ν=c/λ; Ldust=AσT⁴; Lν=AπBν. Gray spherical-grain equilibrium, derived by equating πa²L/(4πr²) and 4πa²σT⁴, gives T=[L/(16πσr²)]¼ and Rsub=[L/(16πσTsub⁴)]½. These are gray-grain formulas, not empirical AGN sublimation-radius calibrations.
- **S2:** [Vazquez et al. 2015](https://arxiv.org/abs/1502.01977), physical motivation for distinct graphite and silicate survival radii. Adopted toy thresholds are 1800 K and 1500 K; composition otherwise has identical gray emissivity. Each material has 12 uniformly spaced radii between its initial Rsub and width × Rsub. Area per radius is 4πr² × 0.1/N, N=12 or 24. This is a chosen area weighting, not a fitted grain distribution.
- **S3:** [Peterson, Theory of Reverberation Mapping](https://ned.ipac.caltech.edu/level5/Sept01/Peterson2/Peter3.html). For an isotropic spherical shell, derive τ=(R/c)(1−cosθ) and uniform cosθ, hence Ψ=c/(2R) for 0≤τ≤2R/c. Lecho(t)=∫Ψ(τ)L(t−τ)dτ. Implemented using 40 equal-weight midpoint delays and linear interpolation on a one-day grid; prehistory is constant at 10⁴⁴ erg/s. Mean delay is R/c.
- **S4:** [WISE photometric calibration](https://irsa.ipac.caltech.edu/data/WISE/docs/release/All-Sky/expsup/sec4_4h.html). m=−2.5 log10(Fν/Fν,0); W1−W2=−2.5 log10[(F1/F2)(171.787/309.540)], with zero points in Jy. Use monochromatic 3.4 and 4.6 μm evaluations, not full bandpass integrations. Fν=Lν/(4πD²), adopting D=100 Mpc with no redshift. Constant host H1=h Fdust,1(0), H2=H1×171.787/309.540 gives zero Vega color. Deriving from total-flux addition gives host dilution Δm=−2.5 log10[(f+h)/(1+h)] for dust brightening factor f.
- **S5:** [Kelly et al. 2009](https://arxiv.org/abs/0903.5315). Exact discrete Ornstein–Uhlenbeck step for log luminosity: x(t+dt)=q x(t)+s sqrt(1−q²)Z, q=exp(−dt/τ), L=L0 exp(x). Here x(0) starts from zero, s is stationary log RMS, Z is standard normal, seed=42, L0=10⁴⁴ erg/s. A fixed-seed linear-congruential generator and Box–Muller transform make runs reproducible.
- **S6:** [Lodato & Rossi 2011](https://arxiv.org/abs/1008.4589), motivation for late fallback ∝t^(−5/3). Chosen TDE-like driver after t0=300 days is L=L0[1+a(1+(t−t0)/τ)^(−5/3)], with L0 before t0. This is a schematic prompt rise plus regularized decay, not a physical TDE bolometric solution. Step and linear inputs are chosen teaching functions: L/L0=1+a H(t−t0) and 1+a min(max((t−t0)/τ,0),1).
- **Toy destruction and recovery prescription:** each shell uses T(Lecho,r); if T>Tsub its surviving fraction becomes zero immediately. Below threshold it remains destroyed unless recovery is enabled, then fnew=1−(1−f)exp(−dt/treform). Areas are multiplied by surviving fraction. This is an effective history of a smoothed shell, not grain-by-grain causal radiative transfer.
- **Toy observations:** one instantaneous visit each cadence days, default 180; Fobs=(Fdust+H)exp(nZ). Noise n is log-flux scatter, approximately fractional scatter when small. No real WISE visit grouping, gaps or uncertainty model. The 0.2 mag peak-to-peak threshold is user-selected for teaching, not an official survey completeness or significance criterion.
- **Derived diagnostics from S1/S4:** host-subtracted F1/F2 is inverted by bisection on Bν(3.4,T)/Bν(4.6,T) over 100–5000 K. Negative fluxes and ratios outside this interval are missing values. “Variable component” here means time-varying dust after exact host subtraction, not difference photometry relative to a baseline. Fit ordinary least squares log10(Tcolor) versus log10(Ldust) using noiseless model points. Fixed area implies slope 1/4; a constant-Tsub moving boundary implies slope 0. A finite mixture with destruction is neither limiting model.

## Limits and interpretation

The program first convolves heating luminosity and then computes temperature, blackbody output and destruction. Nonlinear emission/destruction does not commute with convolution, so this is not an exact observer-frame dust echo. No anisotropy, extinction, shadowing, scattering, thermal inertia, inclination, grain-size physics, distance uncertainty or cosmological corrections are included. The two materials have overlapping radial distributions with separate inner edges, not disjoint stratified surfaces. The total emitting area normalization is illustrative. A single mixture color temperature is not a unique physical temperature, and the host is assumed known exactly. Slopes depend on this mixture and history, and may fall outside 0–0.25.

## Verification

Run `node --test model.test.mjs` for the model tests. The Planck integral test independently checks Stefan–Boltzmann normalization. `verify.cjs` uses an existing Playwright installation via PLAYWRIGHT_PATH and optional CHROME_PATH (or USE_WEBKIT=1); it checks horizontal overflow, page errors, controls and 1440/390 px captures. No browser package is installed by this project. A real iPhone was not tested.
